Projects

Fine-Tuning & Quantization Pipeline for LLMs/VLMs

End-to-end LLMOps pipeline for fine-tuning and quantizing language models using QLoRA 4-bit training. Fine-tuned Qwen2.5-1.5B on Dolly-15k — brought perplexity down from 15.14 to 7.49 (a 50.6% drop) — then quantized with GGUF Q4_K_M for a 68% size reduction. Supports bitsandbytes, GGUF and AWQ backends, served through a FastAPI REST service with Swagger docs, a Gradio demo UI, and full Docker support for one-command deployment.

Self-Healing RAG Pipeline LIVE

A RAG system built around the idea that retrieval can fail — so it shouldn't fail silently. A critic agent evaluates every response for hallucination and auto-retries up to three times with a reformulated query before returning an answer, or an honest "I don't know." Built with Llama 3.3 70B via Groq, a FAISS vector index over PDF chunks using all-MiniLM-L6-v2 embeddings, deployed on Streamlit Cloud with the full reasoning trace visible to the user.

LLM Guardrails Gateway LIVE

A production middleware layer that sits between users and LLMs — blocking jailbreak attempts, PII leakage (email, phone, credit card, SSN) and policy violations before they reach the model, or before the model's response reaches the user. Uses regex classifiers on the input side and an LLM-as-judge on the output side via Groq. Policy rules live in a YAML file so non-engineers can configure them without touching code. FastAPI backend on Render, Streamlit frontend on Streamlit Cloud.
